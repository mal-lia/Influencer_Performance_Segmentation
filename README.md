# Influencer_Performance_Segmentation
This ambitious project is designed to delve into the intricate performance dynamics of 1,000 TikTok influencer accounts, harnessing a multitude of engaging metrics to paint a vivid picture of their social media impact. 

# 📈 Influencer Performance and Segmentation for Marketing Campaigns

## 📌 Project Description

This project focuses on analyzing the performance of 1,000 TikTok influencer accounts using key metrics such as:

- Followers (Subscribers)
- Average Views
- Average Likes
- Average Comments
- Average Shares

The analysis aims to help brands and marketers understand audience characteristics and to develop more effective influencer marketing strategies. This includes segmenting influencers using K-Means Clustering.

The dataset used for this analysis is sourced from Kaggle's TikTok Influencers Dataset (September 2022), which contains 1,000 rows and 8 columns of essential features.

## 🧰 Tools and Libraries

- **Python (Google Colab)**
- **pandas, matplotlib, seaborn**: Data Cleaning and Exploratory Data Analysis (EDA)
- **scikit-learn**: Standardization, Clustering (KMeans), and PCA
- **numpy**: Support for numerical preprocessing

## 🔍 Stages of Analysis

1. **Data Preprocessing**
   - Convert numeric formats such as "1.2M" and "371.9K" to numerical values.
   - Handle missing values, particularly in the account name column.
   - Select key numeric columns for analysis and clustering.

2. **Exploratory Data Analysis (EDA)**
   - Generate descriptive statistics for average comments.
   - Visualize the distribution of followers with a histogram (log scale).
   - Analyze correlations between influencer performance metrics.
   - Identify top influencers based on followers and views.
   - Create a boxplot to illustrate data spread and outliers.

3. **Influencer Segmentation (Clustering)**
   - Select numerical features: Subscribers, Average Views, Average Likes, Average Comments.
   - Standardize features using StandardScaler.
   - Apply K-Means clustering with 3 clusters.
   - Visualize clustering results using PCA (Principal Component Analysis) in 2 dimensions.

## 📊 Key Insights

- A high follower count does not guarantee high engagement; likes and comments are more indicative of real interactions.
- There are outliers, or mega-influencers, with significantly larger than average audiences.
- Shares have the weakest correlation with other metrics, suggesting that shareable content may be influenced by factors such as virality or emotional appeal.
- Segmenting influencers reveals three main groups:
  - Mega Influencers
  - Mid-tier Influencers with high engagement
  - Micro Influencers who are homogeneous and stable

## 🎯 Conclusion

This project demonstrates that analyzing influencer performance should not rely solely on follower numbers; it must also consider the interactions generated by each post. Through EDA and clustering, we can achieve influencer segmentation that serves as a foundation for developing sharper and more measurable marketing campaign strategies.
